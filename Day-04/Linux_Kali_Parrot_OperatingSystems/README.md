## 🐧 What is Linux?

Linux is an open-source operating system based on the Linux kernel.

It is widely used in:

- Cybersecurity
- Networking
- Cloud computing
- System administration
- Software development
- Digital forensics

---

## 🔐 Why Linux is Important in Cybersecurity

Linux provides:

- Powerful command-line tools
- Flexible system configuration
- Networking utilities
- Scripting and automation capabilities
- Security and forensic tools
- A strong environment for cybersecurity labs

---

## ⚔️ Kali Linux

Kali Linux is a Debian-based Linux distribution designed for penetration testing, security research, digital forensics and security assessments.

Some common cybersecurity areas include:

- Network security
- Web application security
- Vulnerability assessment
- Digital forensics
- Wireless security
- Security research

---

## 🦜 Parrot OS

Parrot OS is another Debian-based Linux distribution focused on security, privacy and development.

It can be used for:

- Cybersecurity labs
- Privacy-focused computing
- Security research
- Development
- Digital forensics

---

## 💻 Basic Linux Commands

| Command | Purpose |
|---|---|
| `pwd` | Shows current directory |
| `ls` | Lists files and directories |
| `cd` | Changes directory |
| `mkdir` | Creates a directory |
| `touch` | Creates a file |
| `cp` | Copies files |
| `mv` | Moves or renames files |
| `rm` | Removes files |
| `cat` | Displays file contents |
| `whoami` | Shows current user |
| `uname -a` | Shows system information |

---

## 🖥️ Installing Kali Linux / Parrot OS in a VM

Basic installation process:

1. Download the official ISO.
2. Install VirtualBox or VMware.
3. Create a new virtual machine.
4. Allocate RAM and storage.
5. Attach the ISO file.
6. Start the virtual machine.
7. Follow the installation wizard.
8. Complete the initial configuration.
9. Update the operating system.

Using a virtual machine provides an isolated environment for learning and practicing cybersecurity.
